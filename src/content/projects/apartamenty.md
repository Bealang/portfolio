## O projekcie

**Apartamenty** jest prototypem nowej odsłony strony dla apartamentów. Ma na celu prezentację oferty oraz ułatwienie rezerwacji. W przyszłości planujemy rozbudować system o wiele nowości.

### Co zrobiliśmy?

- **Panel obsługi** — intuicyjny panel do zarządzania rezerwacjami (usuwanie, meldowanie, wymeldowanie)
- **System rezerwacji** — prosty system rezerwacji z kalendarzem i formularzem kontaktowym
- **Optymalizację wydajności** — lekki kod bez zbędnych frameworków
- **Zabezpieczenia** - dane klientów są zabezpieczone przed niepowołanym dostępem

### Technologie

- Node.js
- PostgreSQL
- HTML
- CSS
- Javascript
- React
